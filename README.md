## Competencias Desarrolladas

- Diseño de modelos conceptuales MER y MER-E (jerarquías, entidades débiles)
- Normalización de bases de datos (1FN, 2FN, 3FN)
- Transformación de modelos lógicos a modelos relacionales
- Implementación física con sentencias SQL DDL (CREATE TABLE, ALTER TABLE)
- Poblamiento de datos con sentencias DML (INSERT, IDENTITY, SEQUENCE)
- Recuperación de datos con SELECT, WHERE, BETWEEN, IN, LIKE, IS NULL, ORDER BY
- Operadores lógicos (AND, OR, NOT) y concatenación
- Definición de restricciones de integridad (PK, FK, UNIQUE, CHECK, NOT NULL)
